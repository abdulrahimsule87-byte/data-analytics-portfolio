# Adidas Sales Data Analysis

## 1. Project Overview

This project involves analysing Adidas sales data using Microsoft Excel to identify sales trends, business performance and meaningful insights.

## 2. Project Objectives

- Analyse Adidas sales performance.
- Identify top-performing products.
- Examine regional sales performance.
- Evaluate sales trends over time.
- Develop an interactive dashboard.

## 3. Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel formulas
- Data cleaning
- Data visualisation

## 4. Project Methodology

1. Data cleaning and preparation.
2. Data exploration.
3. Data analysis using PivotTables.
4. Creation of charts and visualisations.
5. Dashboard development.
6. Interpretation of findings.

## 5. Skills Demonstrated

- Data cleaning
- Data analysis
- Data visualisation
- Dashboard development
- Business intelligence

## 6. Project Outcomes

This project demonstrates the application of Microsoft Excel in transforming raw sales data into meaningful information for business decision-making.
